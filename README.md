# Pokedex Database
How to operate the Pokedex

Setting Up:

1. Create a Database named "Pokemon" in PostgreSQL
2. Change the password to your PostgreSQL password in the DatabaseProject.py file. Run that file afterwards. This creates the Tables and their Attributes for the Entities.
3. Change the password to your PostgreSQL password in the PokemonTable.py file. Run that file afterwards. This fills in the Pokemon and Generation Tables.
4. Change the password to your PostgreSQL password in the TypeID.py file. Run that file afterwards. This fills in the Type Tables.
5. Change the password to your PostgreSQL password in the Pokedex_Type.py. Run that file afterwards. This fille in the pokemon_type Table.
6. Finally, change the password to your PostgreSQL password in the Pokemon_GUI.py file. Run that file to start the program.

Using the Program:

1. Type your desired Pokemon into the search bar
2. Once typed in, click the down arrow in the Combobox to open up suggestions that match your search. Select which Pokemon you want.
3. Your searched Pokemon will give you their name, type(s), evolution, Pokedex Number, and a sprite image of the Pokemon.
4. Use the "Next" and "Previous" arrows to navigate to the previous and next Pokedex Number, giving you the Pokemon that matches.
